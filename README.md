# 官公需情報ポータルサイト 入札公告

国の機関・独立行政法人・地方公共団体が出した入札公告を、SQL で検索・集計できるテーブルにしたデータセットです。[官公需情報ポータルサイト](https://www.kkj.go.jp/s/)（中小企業庁）が各機関のサイトから集めた公告を、2021 年 4 月以降の分から収録し、毎日更新します。

## 出典と利用条件

官公需情報ポータルサイトの検索 API を利用して取得し、加工しています。

- 使うときは、官公需情報ポータルサイトの API を利用したデータであることを明記し、https://www.kkj.go.jp/s/ へのリンクを付けてください（官公需情報ポータルサイトの利用規約）
- 公告の権利は各発注機関にあります。入札に参加する前に、`document_url` の公告か発注機関のサイトで公式の情報を確認してください

## テーブル

| テーブル | 内容 |
| --- | --- |
| `tender.notices` | 1 行が 1 公告。件名・発注機関・都道府県と市区町村・カテゴリー・公告日・入札日・開札日・公告文・添付ファイル |

## 使い方

つくば市で今月公告された入札:

```sql
SELECT cft_issue_date, project_name, category, document_url
FROM kkj.tender.notices
WHERE city_code = '08220' AND cft_issue_date >= date_trunc('month', current_date)
ORDER BY cft_issue_date DESC;
```

公告文に「測量」を含む工事を、都道府県ごとに数える:

```sql
SELECT prefecture_name, count(*) AS notices
FROM kkj.tender.notices
WHERE description LIKE '%測量%'
GROUP BY ALL
ORDER BY notices DESC;
```

## 収録範囲の注意

- ポータルが集めた機関・公告だけを含みます。すべての発注機関を網羅しているわけではありません
- 落札者と落札金額は含みません
- カテゴリー・公示種別・入札日・開札日などは、多くの公告で原典に無く NULL です。カテゴリーと公示種別は原典の文字のままで、「物品の購入」のような表記ゆれがあります
- 公告日（`cft_issue_date`）は、原典に公告日が無いときはポータルが公告を取得した日です
- 国の機関などでは都道府県コードが NULL のことがあります

## 取得方法

検索 API は検索語・件名・機関名・都道府県のどれかが必須で、全件を返す呼び出し方がありません。検索語に「NOT 存在しない語」を指定するとほかの条件に合う全件が返るので、公告日を 1 日ずつ指定して取得しています。1 回に返るのは 1,000 件までなので、1 日で 1,000 件を超えたときは、検索語を「語を含む」と「語を含まない」に分けて取り直します。

公告は公開から 1 日ほどたってポータルに登録されるため、毎回、前回取得した最後の公告日の 30 日前から取り直し、まだ無い公告だけを追記します。過去分は 1 回に 180 日分ずつ取得します。

```bash
uv sync
scripts/build.sh   # 取得して dbt build し、Queria に公開する
```
